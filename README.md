AbotAgri 🌱
AbotAgri ("Abot sa Agrikultura") is a mobile-friendly marketplace platform designed to connect local farmers directly with businesses and buyers. The app allows farmers to list their agricultural products, and buyers to browse, order, and communicate with sellers — all in real time. Built with FlutterFlow and Firebase, AbotAgri aims to empower local agriculture through digital transformation.

🚀 Features
  -Farmer and buyer registration/login (email & password)
  -Crop listing with images, quantity, and pricing
  -Real-time marketplace browsing and orderin
  -In-app chat between farmers and buyers

🛠️ Built With
  -Frontend: FlutterFlow (Flutter)
  -Backend: Firebase Firestore & Firebase Authentication
  -Deployment: FlutterFlow Web App (PWA enabled)

📦 Setup & Installation
  1. Clone the repository
     -git clone https://github.com/your-username/abotagri.git  
cd abotagri
  2. Import to Flutter (if exported from FlutterFlow)
    -Make sure you have Flutter SDK installed.
    -Open the project folder in VS Code or Android Studio.
     
  3. Install dependencies
     - flutter pub get

  4. Connect to Firebase
     - Set up a Firebase project
     - Add your google-services.json (for Android) and GoogleService-Info.plist (for iOS) in the respective directories
     - Make sure Firestore and Authentication are enabled in Firebase Console

  5. Run the app
     - flutter run
    
🔒 Notes
    This app currently uses email & password authentication. Future updates will include phone auth and role-based accounts.
    Chat, ordering, and listing features are functional, while some features like checkout and delivery tracking are still in progress.
